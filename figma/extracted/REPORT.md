## Limits

- Authored preview states are not a complete Cartesian Figma variant matrix.
- DOM trees are component templates and enhanced default examples, not native Figma nodes.
- Computed values and matching CSS rules are evidence, not inferred variable bindings.
- Figma font availability and prototype behavior remain unverified.
- Live timers, overlays opened after interaction, and responsive layouts require a later capture pass.
- Code Connect mappings have not been created.
