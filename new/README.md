# Syntari /new

Three product-ready compositions implemented against Syntari's current tokens and component foundations.

## Routes

- \`/new/command-palette/\`
- \`/new/revenue-card/\`
- \`/new/team-projects-report/\`

## Structure

- \`new.css\` contains composition-only layout and presentation. It does not redefine Syntari primitives or semantic tokens.
- \`new.js\` adds interaction and data state.
- \`manifest.json\` describes primitive dependencies and states for agents and future registry promotion.

These are deliberately compositions rather than replacements for the authored registry primitives they use.
