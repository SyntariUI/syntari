A few things to know.

    
What can I build with Syntari?
Use the components to build dashboards, product interfaces, and agent workflows. The Renderer demonstrates three authored screen patterns that you can inspect and adapt.

    
Can an AI agent use the design system?
Yes. The CLI and machine-readable registry expose components, dependencies, examples, tokens, and validation rules. Start with the implementation docs and agent policy.

    
Can I customize the components?
Yes. Installation gives you editable source. Shared tokens control the visual language, and the MIT license allows personal and commercial use.
